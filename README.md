# Discord Argue Bot 🤖🔥

An interactive Discord entertainment bot built using Python and discord.py.

This bot is designed to make Discord servers more engaging through:
- Dynamic argument responses
- Roast commands
- Meme GIF integration
- Daily song recommendations
- Hot takes and debate systems
- Randomized entertainment features


## Features

# 🧠 Automatic Argument System
The bot randomly argues with users in chat to create entertaining interactions.

### 🔥 Roast Command

$roast

Generates random roast responses.

😂 Meme Command

$meme

Sends random meme GIFs.

🎵 Daily Song Recommendation

$song

Provides a daily randomized music recommendation.

⚔️ Debate Command

$argue <topic>

Makes the bot argue against any topic.

📊 Rating Command

$rate <anything>

Rates any topic from 1–10.

💪 Motivation Command
$motivate

Returns aggressive motivational quotes.

🗣️ Hot Take Generator
$hottake

Generates random controversial opinions.

#Installation

Clone Repository

git clone https://github.com/YOUR_USERNAME/discord-chaos-bot.git

Navigate to Project

cd discord-chaos-bot

**Install Dependencies**

pip install -r requirements.txt

#Environment Variables

Create a .env file:

TOKEN=your_discord_bot_token

**Running the Bot**

python bot.py

**Discord Setup**

1. Create an application in the Discord Developer Portal

2. Create a bot

3. Enable Message Content Intent

4. Copy token into .env

5. Invite bot using OAuth2 URL Generator

6. Discord Developer Portal:
   https://discord.com/developers/applications
